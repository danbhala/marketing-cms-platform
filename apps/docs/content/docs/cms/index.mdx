---
title: CMS adapters
description: "One interface, six implementations. What each adapter does and how the CMSs differ."
---

Every adapter implements `CmsAdapter` from `@platform/cms-core` and ships four things: a **schema generator** (the content model in that CMS's native format), a **transform** (raw entries → canonical content, validated with zod), **preview** (enter Draft Mode, parse the editor's context, attach `$edit`, a client bridge), and a **webhook** mapper (verify the signature, turn the payload into cache tags).

|                 | Contentful                           | Storyblok                                    | Optimizely SaaS                                  | Sanity                                        | Drupal                                                                   | Wagtail                                                      |
| --------------- | ------------------------------------ | -------------------------------------------- | ------------------------------------------------ | --------------------------------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------ |
| Schema output   | `contentful-migration` script + JSON | Components JSON for the Management API / CLI | SDK content-type definitions (TS) + JSON         | Schema types for the Studio + JSON            | `platform_content` module: config YAML (paragraph types, fields)         | Django app (`blocks.py`, `models.py`, `api.py`) + JSON       |
| Published reads | Content Delivery API                 | CDA `version=published`                      | Optimizely Graph                                 | `perspective: "published"` (CDN)              | JSON:API, anonymous                                                      | Pages API v2 (`find/?html_path=`)                            |
| Draft reads     | Content Preview API                  | CDA `version=draft` + preview token          | Graph preview query with URL token               | `perspective: "drafts"` + viewer token, stega | JSON:API `resourceVersion=rel:working-copy` + OAuth client               | `wagtail-headless-preview` token → `page_preview`            |
| Rich text       | Contentful Document                  | ProseMirror JSON                             | XHTML / structured                               | Portable Text                                 | `text_long` HTML                                                         | HTML (`rich_text_format=html`)                               |
| Click-to-edit   | Inspector mode: entry + field        | Block level: `data-blok-*`                   | `data-epi-block-id` / `data-epi-edit` (edit ctx) | `data-sanity` document + path                 | `data-drupal-entity` / `data-drupal-edit` (entity level)                 | `data-wagtail-*` ids + "Edit in Wagtail" (no in-page editor) |
| Save → refresh  | Live preview SDK event               | Bridge `input` event                         | `optimizely:cms:contentSaved`                    | Visual editing `refresh`                      | Iframe reload by the `next` module; bridge refreshes on focus            | Preview panel reloads the iframe                             |

## Switching

```bash
# apps/web/.env.local
CMS_PROVIDER=storyblok
STORYBLOK_PREVIEW_TOKEN=…
```

Then generate and push the schema (`pnpm --filter @platform/cms-storyblok schema:generate`), configure the preview URL and webhook in the CMS, and run `pnpm dev`. Nothing else changes.
