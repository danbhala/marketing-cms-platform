<Callout type="info">The adapter lives in `packages/cms-optimizely`. Its README has the step-by-step setup; this page is the summary.</Callout>

## Environment

`OPTIMIZELY_CMS_URL, OPTIMIZELY_GRAPH_SINGLE_KEY, OPTIMIZELY_GRAPH_SECRET, PREVIEW_SECRET, REVALIDATE_SECRET` (see `apps/web/.env.example`).

## Push the content model

```bash
pnpm --filter @platform/cms-optimizely schema:generate
# then
pnpm --filter @platform/cms-optimizely schema:generate, then push with the Optimizely CMS CLI (see the package README)
```

The generated files are committed under `packages/cms-optimizely/schema/` so diffs show exactly what changes in the CMS when the content model changes.

## Preview

Preview URL: `https://your-site/api/preview?key={key}&ver={ver}&loc={loc}&ctx={ctx}&preview_token={token} (Settings → Applications → Hostnames)`.

In draft mode the adapter reads drafts, attaches this CMS's live-edit attributes to every block, item and field, and loads the bridge that refreshes the page on save. See [Preview & visual editing](/docs/preview).

## Webhook

Optimizely Graph webhook → https://your-site/api/revalidate. The adapter verifies the request and maps the payload to cache tags; see [Caching](/docs/caching).
