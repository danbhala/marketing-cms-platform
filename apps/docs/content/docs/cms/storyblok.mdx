<Callout type="info">The adapter lives in `packages/cms-storyblok`. Its README has the step-by-step setup; this page is the summary.</Callout>

## Environment

`STORYBLOK_PREVIEW_TOKEN, STORYBLOK_REGION, STORYBLOK_WEBHOOK_SECRET, PREVIEW_SECRET, REVALIDATE_SECRET` (see `apps/web/.env.example`).

## Push the content model

```bash
pnpm --filter @platform/cms-storyblok schema:generate
# then
storyblok push-components --space <id> packages/cms-storyblok/schema/components.json
```

The generated files are committed under `packages/cms-storyblok/schema/` so diffs show exactly what changes in the CMS when the content model changes.

## Preview

Preview URL: `https://your-site/api/preview (Settings → Visual Editor → default environment); the editor appends _storyblok and _storyblok_tk`.

In draft mode the adapter reads drafts, attaches this CMS's live-edit attributes to every block, item and field, and loads the bridge that refreshes the page on save. See [Preview & visual editing](/docs/preview).

## Webhook

Settings → Webhooks → Story published/unpublished → https://your-site/api/revalidate, with the webhook secret. The adapter verifies the request and maps the payload to cache tags; see [Caching](/docs/caching).
