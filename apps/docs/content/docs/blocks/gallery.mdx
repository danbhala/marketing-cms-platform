## Layouts

| Layout     | What it does                                                                                                                                                                        |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `grid`     | Equal 4:3 tiles, two per row on phones and `columns` on desktop.                                                                                                                    |
| `masonry`  | Natural heights flowing down columns, for mixed portrait and landscape.                                                                                                             |
| `featured` | The first item fills a 2×2 cell; the rest are squares.                                                                                                                              |
| `stage`    | One large image with a thumbnail row and a crossfade between them. `autoplay` advances every five seconds with a progress bar; it pauses on hover and focus and has a pause button. |
| `strip`    | A row that moves sideways as the page scrolls down. Phones and reduced-motion settings get a swipeable row instead.                                                                 |

With `lightbox` on, every tile is a button that opens the item full screen: it morphs from its tile (Motion's `layoutId`), with previous and next, swipe on touch, arrow keys, and focus returned to the tile on close. Videos play with their native controls in the lightbox.

Alt text comes from the media, then the caption, then the item's position, so every tile has a name.
