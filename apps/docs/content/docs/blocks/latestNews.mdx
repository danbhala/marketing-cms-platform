title: Latest news
description: "The newest few items of a document type, for a home page, with a link to the full listing."
---

A home page or landing page version of the [Collection](/docs/blocks/collection) block: three, four or six newest items, optionally from one category, with a "see all" link, in the same four layouts (grid, list, featured, compact). No filters, no pagination. The host app resolves the items from the same cached collection read the listing uses, so publishing a story refreshes both. When the action is left empty the link goes to the first page that has a `collection` block of the same type.
