---
title: Collection
description: "A filterable, searchable, paginated listing of one document type, driven by the URL."
---

The block lists `article` documents with category chips, an optional search box, a sort select and numbered pagination, in one of four layouts: a card grid, rows with a thumbnail, the newest item featured above a grid, or a compact title-and-date list. Every state is a URL; see [Listing pages](/docs/listing-pages) for the URL contract, layouts, rendering and caching.
