`apps/web` is intentionally small:

| File                                   | Purpose                                                                                                                                                             |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `cms.config.ts`                        | `siteConfig` (locales, site URL, default theme) and `getAdapter()`, which picks the adapter from `CMS_PROVIDER`. The only file allowed to import `@platform/cms-*`. |
| `cms.bridges.ts`                       | Lazy map of provider → live-editing bridge, used by the client `PreviewBridge`.                                                                                     |
| `lib/cms.ts`                           | `'use cache'` reads for published content with cache tags.                                                                                                          |
| `components/collection-block.tsx`      | Binds the `collection` block to the request: filter bar and results each await `searchParams` inside their own Suspense boundary.                                   |
| `components/latest-news-block.tsx`     | Binds the `latestNews` block to the adapter: reads the newest articles (optionally one category) through the same cached collection read the listing uses.          |
| `lib/breadcrumb-trail.ts`              | Builds the breadcrumb trail from the URL and ancestor page titles.                                                                                                  |
| `lib/alternates.ts`                    | The same path in every other locale that publishes it: hreflang tags, sitemap alternates and the language links.                                                    |
| `app/[locale]/layout.tsx`              | Root layout: `<html>` with the default theme, `UiProvider` (next/link, next/image), Suspense.                                                                       |
| `app/[locale]/[[...slug]]/page.tsx`    | Every CMS page and article. `generateStaticParams` from the adapter's paths; metadata from the document's SEO fields and, on listing pages, the query.              |
| `app/api/preview`, `/api/preview/exit` | Enter/leave Draft Mode.                                                                                                                                             |
| `app/api/revalidate`                   | The webhook endpoint.                                                                                                                                               |
| `proxy.ts`                             | Locale redirect and `frame-ancestors`.                                                                                                                              |
| `app/sitemap.ts`, `app/robots.ts`      | From the adapter's paths.                                                                                                                                           |

## Configuration

```ts
// next.config.ts
const nextConfig: NextConfig = {
  cacheComponents: true,
  partialPrefetching: true,
  reactCompiler: true,
  typedRoutes: true,
  transpilePackages: ["@platform/ui", "@platform/content-model" /* … */],
  images: { remotePatterns: [/* each CMS's asset host */] },
}
```

The CMS route exports `instant = false`: every byte of a CMS page depends on the path, so there is no URL-independent shell for Partial Prefetching to share, and the instant-navigation check would only flag that. Listing links use `prefetch` and prefetch their full cached content.

CMS-authored hrefs are not statically known, so the UI provider casts them to `Route`.

## Languages

`siteConfig.locales`, `defaultLocale` and `localePrefix` drive every URL. With `"always"` each URL starts with its locale (`/fr/about`); with `"as-needed"` the default locale has none (`/about`). `localePath()` builds those paths, and the UI provider's `Link` runs CMS hrefs through `localizeHref()`, so a link to `/about` on a French page goes to `/fr/about`.

A page lists itself in each other locale that publishes it: as `<link rel="alternate" hreflang>` tags with `x-default` pointing at the default locale, as `xhtml:link` alternates in the sitemap, and as language links in the utility bar and footer. Those links only show when there are two or more.

When a CMS gives each language its own slug (`/fr/a-propos` for `/about`), its adapter implements `getTranslatedPaths`, which returns the page's path in each locale; without it, a translation is the same path. Links in CMS content carry the default slug, so `/fr/about` redirects to `/fr/a-propos`. Storyblok supports this through the Translatable Slugs app, and the local adapter through its `translatedPaths` option; the other adapters match by path for now.

## Environment

See `apps/web/.env.example`. `CMS_PROVIDER`, `SITE_URL`, `PREVIEW_SECRET`, `REVALIDATE_SECRET` are shared; the rest are per CMS. `SITE_NOINDEX=true` keeps a demo or staging deployment out of search engines: `robots.txt` disallows everything and every page gets a `noindex` meta. The hosted demo at [marketing-cms-platform-demo.vercel.app](https://marketing-cms-platform-demo.vercel.app) runs this way on the `local` adapter.
